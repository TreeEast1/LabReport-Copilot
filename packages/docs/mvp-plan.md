# LabReport Copilot MVP 开发计划

## 第一阶段目标

围绕“组会汇报 Agent 工作流”完成一个可运行、可演示、可继续开源演进的 MVP。

## P0 范围

1. 首页
2. 用户科研画像页
3. 导师画像页
4. 材料库页面
5. 组会报告生成页面
6. 历史记录页面
7. Markdown 导出
8. FastAPI 基础接口
9. 本地 JSON 持久化

## P1 范围

1. 论文调研工作流
2. 多模态图片分析工作流
3. 飞书导出接口预留

## P2 范围

1. 语音输入工作流
2. 向量检索增强
3. 多 Agent 编排优化
4. 多模板系统

## 当前实现策略

- 前端先以本地表单与后端 API 联调完成闭环
- 后端以规则化模板 + 模拟 Agent 输出先打通主流程
- 所有 AI 能力通过服务接口抽象，后续再替换为真实模型调用

## 里程碑

1. 项目结构与文档初始化
2. 前端页面骨架完成
3. 后端领域模型与 API 完成
4. 组会报告主流程联调完成
5. README、环境变量、启动方式补齐
